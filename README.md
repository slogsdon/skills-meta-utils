# skills-meta-utils

Meta-utility skills for Claude Code. 2 skills for local LLM delegation and skill authoring.

Install via the [slogsdon-claude-code-config marketplace](https://github.com/slogsdon/claude-code-config).

## Skills

- **qwen-executor** — Delegates tasks to local Qwen via LM Studio
- **write-a-skill** — Guides writing a new skill following Shane's authoring conventions

`compress-prompt` was removed in 0.2.0 — see [CHANGELOG.md](CHANGELOG.md).
