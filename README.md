# skills-meta-utils

Meta-utility skills for Claude Code. 2 skills for token-efficient prompt compression and local LLM delegation via Qwen.

Install via the [slogsdon-claude-code-config marketplace](https://github.com/slogsdon/claude-code-config).

## Skills

- **compress-prompt** — Token-efficient prompt compression via Qwen
- **qwen-executor** — Delegates tasks to local Qwen via LM Studio
